# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on the repository page open **Security → Report a
vulnerability**. If that option is not offered, contact the repository owner through their
GitHub profile and ask for a private channel before sending details. Describe what you found, how to reproduce it, and what an attacker could do
with it. If you can, include the version or commit you tested.

You can expect an acknowledgement, an assessment, and — if the report is confirmed — a fix
with credit to you unless you prefer otherwise. Please give the maintainer reasonable time
to fix the problem before making it public.

## Supported versions

The project is under active development; fixes are made on the `main` branch.

## What is in place

The security measures of the project, the tests that hold them in place, and their limits
are described in [`docs/architecture/security.md`](docs/architecture/security.md).

# Güvenlik Politikası

Bir güvenlik sorunu için lütfen herkese açık bir kayıt (issue) açmayın. GitHub üzerinden
özel olarak bildirin: depo sayfasında **Security → Report a vulnerability**. Ne bulduğunuzu,
nasıl yeniden üretileceğini ve bir saldırganın bununla ne yapabileceğini yazın.

Düzeltmeler `main` dalında yapılır. Projedeki güvenlik önlemleri, bunları sınayan testler ve
sınırları [`docs/architecture/security.md`](docs/architecture/security.md) belgesinde
anlatılmıştır.
